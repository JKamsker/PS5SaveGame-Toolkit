Processing ran outside the checkout with Python `-I` and Pillow: allowlisted image headers, Pillow verification, maximum 64×64 pixels (aspect ratio retained), WebP quality 82 / method 6 or PNG-8 (256 colours) when smaller; identical processed hashes share a path. Class badges were selected explicitly rather than inferred from class-page screenshots. The F2 host validates and caches packs once; plugins only resolve pinned in-memory records/assets. No runtime fetches, image conversion or file I/O.
