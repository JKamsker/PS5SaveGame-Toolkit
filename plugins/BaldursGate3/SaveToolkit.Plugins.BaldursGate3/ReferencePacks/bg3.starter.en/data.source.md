# BG3 attributed catalog data

The original label subset contains factual labels, categories and technical identifiers
with original uncertainty annotations by PS5 Save Game Toolkit contributors.
Version 1.2.0 adds separately attributed Larian game icons and short game-tooltip/
flavour-text excerpts under the owner decision dated 2026-10-29. See
[assets.source.md](assets.source.md) for every exact page/file revision, original
image hashes, byte counts and transformations. No legacy wiki editorial prose is copied.

The source pages are pinned to permanent oldid revisions in each record. The pack
uses the CC BY-SA option for post-2024-compatible material and excludes legacy
expressive content whose licence may be CC BY-NC-SA. A page revision footer that
offers both licences is not treated as permission to copy legacy prose. Retain this
file, pack.json, the record-level source links and the share-alike terms when
redistributing the data adaptation.
