# Community data provenance

This sidecar records the factual/text-only community export additions for the Gearbox plugin. The source revision is `a1c54a2fd6c190029e3e724ac0a0a5c65d3b4fc2` (`https://github.com/sandsmark/borderlands3-save-editor/tree/a1c54a2fd6c190029e3e724ac0a0a5c65d3b4fc2`). The imported records are pinned by the SHA-256 values in `pack.json`.

The data has no published licence. It is reused with attribution under the owner decision dated 2026-10-28: **No licence published; reused with attribution per owner decision 2026-10-28**. The converter reimplemented the reader and did not copy upstream code.
