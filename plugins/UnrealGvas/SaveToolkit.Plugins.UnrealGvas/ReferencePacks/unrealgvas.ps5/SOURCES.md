# Unreal GVAS PS5 reference pack

This pack contains serialized property captions plus four attributed Sackboy costume thumbnail references. It contains no sample bytes or decoded PS5 image payloads. Pack version `1.2.0` applies to PPSA01288 and PPSA02199; costume art is reference-only and does not claim a saved-ID join.

Every dataset repeats its attribution in `pack.json`; the UI shows that attribution on catalogue fields and schema image cells. Unknown limits and ownership are intentionally omitted. No private values are bundled.

## Costume thumbnails (retrieved 2026-10-29)

[Imagisphere's Sackboy costume icon category](https://wiki.imagisphere.me/Category:Sackboy:_A_Big_Adventure_Costume_Icons) and its individual file pages identify the Amazon Bird Of Paradise and Amazon Lion pieces. Rights are reserved by Sony Interactive Entertainment / Sumo Digital; the owner decision of 2026-10-29 permits this attributed embedding. The four files are downscaled to 64x64 WebP in `unrealgvas_sackboy_costume_art` and surfaced only as read-only reference thumbnails.

The existing GVAS image metadata dataset still describes compressed raw image payloads. No extractor implementation, article prose, or PS5 pixel-layout claim is embedded; undecoded save fields remain labelled Undecoded.
