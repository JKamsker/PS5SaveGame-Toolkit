# Unreal GVAS PS5 evidence pack

This pack contains only serialized property names and descriptions authored from the privately
retained PS5 samples in the project evidence log. It contains no sample bytes, game assets, icons,
localization strings or copied third-party code. The Sackboy image metadata source is the MIT-licensed
GingerBreadImageExtractor research and article; PC pixel-layout claims are retained as research only
and are not presented as verified PS5 facts.

Every dataset repeats its attribution in `pack.json`; the UI shows that attribution on each catalog
field. Unknown limits are intentionally omitted. Pack version `1.1.0` adds original named storage
captions and Jedi settings/journey entries; it is evidence for PPSA01288 and PPSA02199, not a claim
about other releases. Runtime title overlays additionally require the observed class/engine/package
signature. No game-specific ID-to-wiki joins are asserted.

## Original caption datasets (retrieved 2026-10-28)

Sackboy fields (24), Jedi actor/journey fields (12), and Jedi settings fields (6):
[PS5 Save Game Toolkit contributors](https://github.com/JKamsker/PS5SaveGame-Toolkit),
[GPL-3.0-or-later](https://www.gnu.org/licenses/gpl-3.0.html). Captions are independently authored
from observed serialized property names. Apparent meanings are Inferred; storage names are evidence,
not valid ranges, ownership, prerequisites or proven gameplay effects. No private values are bundled.

Record `source` URLs point to Imagisphere world/shop guides and PowerPyx's Jedi collectible guide
for optional external research. Their prose, lists, item IDs, prices, media and icons were **not**
imported. No license for that content is inferred from the toolkit's own original caption license.
The GingerBread reflected scaffold and SackboyWorldUnlocker likewise remain research-only links:
no unlicensed code/data was copied. No CC BY-SA text was adapted this round.
