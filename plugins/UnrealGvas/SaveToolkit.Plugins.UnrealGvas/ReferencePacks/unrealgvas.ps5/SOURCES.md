# Unreal GVAS PS5 evidence pack

This pack contains only serialized property names and descriptions authored from the privately
retained PS5 samples in the project evidence log. It contains no sample bytes, game assets, icons,
localization strings or copied third-party code. The Sackboy image metadata source is the MIT-licensed
GingerBreadImageExtractor research and article; PC pixel-layout claims are retained as research only
and are not presented as verified PS5 facts.

Every dataset repeats its attribution in `pack.json`; the UI shows that attribution on each catalog
field. Unknown limits are intentionally omitted. Pack version `1.0.0` is build-agnostic evidence for
PPSA01288 and PPSA02199, not a claim about other releases.
