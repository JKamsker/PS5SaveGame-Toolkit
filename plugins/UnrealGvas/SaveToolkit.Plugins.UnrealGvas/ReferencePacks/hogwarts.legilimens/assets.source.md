# Hogwarts visual reference assets

- Gear icons: [Hogwarts Legacy Gear icon mirror](https://cdn.eip.gg/hogwarts-legacy/icons/gear/), retrieved 2026-10-29. The mirror exposes exports from `Phoenix/Content/UI/Icons/Gear`; eight files are downscaled to 64x64 WebP. Rights reserved by Warner Bros. Games / Portkey Games; used with attribution per owner decision 2026-10-29. Internal icon names are retained; friendly gear-name and icon joins are **Inferred**, not PS5 row matches.
- Gear descriptions: [HogwartsLegacy.GamesRef.com gear database](https://hogwartslegacy.gamesref.com/gear), retrieved 2026-10-29. Short game UI descriptions are transcribed for eight entries; no ownership, rarity, stat, or save-ID claim is made. Rights reserved by Warner Bros. Games / Portkey Games; used with attribution per owner decision 2026-10-29.
- Map: original 800x800 schematic authored for this plugin by PS5 Save Game Toolkit contributors. Region labels follow the MIT Legilimens catalogue in `collectibles.source.md`; markers use the existing 0–100 schematic grid. This is an original work, GPL-3.0-or-later, with no copied publisher map pixels.
- Processing: source images were treated as untrusted data, validated by Pillow in isolated mode, downscaled outside the repository, and encoded as WebP. No downloaded code was executed.
