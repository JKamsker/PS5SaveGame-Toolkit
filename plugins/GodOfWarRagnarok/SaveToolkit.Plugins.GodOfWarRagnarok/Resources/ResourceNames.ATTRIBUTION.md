# ResourceNames.json attribution

This 31-entry direct-call fallback uses the same factual ID/name crosswalk as the embedded
`ReferencePacks/gow-ragnarok.ps5.en` pack. Names and broad categories are adapted from the
[God of War Wiki Ragnarök resources page](https://godofwar.fandom.com/wiki/Resources/GOW_%28Ragnar%C3%B6k%29),
licensed **CC-BY-SA-3.0** under [Fandom's licensing terms](https://www.fandom.com/licensing).
Hash bytes were normalized from the cited community resource table and checked against PPSA08330
sample occurrences. No game artwork, trainer code or copied prose is included; legal quantity limits
are unknown. See the plugin README's Sources and attribution section for the complete source list.
