names/categories from Astro's Playroom Wiki and Astro Bot Wiki contributors, with
original selection, saved-key joins and annotations by PS5 Save Game Toolkit
contributors. Retrieved 2026-10-28. Every record links its source/context article.

Retain the article links, author credits, modification notice and share-alike terms
when redistributing or adapting it. The full source/access/scope record is in the
pack's `data.source.md`; dataset attribution and file hashes are in `pack.json`.
The Sources panel and catalogue row details expose attribution offline.

The original 1.0.0 alias dataset copied no wiki descriptive prose, game-authored flavor text,
artwork, icons, screenshots, maps, community editor source or third-party parser implementation.
Artifact aliases include Inferred candidate world keys where the observed catalogue has a matching
world path. Puzzle aliases include only Inferred internal-stage `stageKey` joins; physical locations and
ordinals remain unresolved. Prop names are original raw-key aliases, explicitly unresolved. The licence
of the data adaptation does not relicense the independently implemented plugin code.

The F9 layout is original Toolkit work under GPL-3.0-or-later (2026-10-28), with provenance in
`AstroSpatialViews.source.md` and MapNode. It uses eight-column list-order positions, not community
coordinates or game artwork. Existing displayed catalogue names retain their CC BY-SA attribution.
The original 0.4.0 integration linked PowerPyx/Gage externally only. Version 0.5.0 adds the
separately attributed publisher material below; no guide walkthrough prose or code is copied.
