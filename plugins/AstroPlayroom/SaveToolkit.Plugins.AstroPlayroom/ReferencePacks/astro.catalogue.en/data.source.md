# ASTRO's PLAYROOM catalogue candidates

Retrieved 2026-10-28. Authors: Astro's Playroom Wiki contributors, Astro Bot Wiki
contributors, and PS5 Save Game Toolkit contributors (selection, exact saved-key
joins, original raw-key aliases and uncertainty annotations).

This adaptation (`collectibles.json`, `worlds.json`, including annotations) remains
under [CC BY-SA 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/).
Retain these credits, the per-record article URLs, modification notice and
share-alike terms on redistribution/adaptation. These data terms do not relicense
the plugin code. [Fandom's licensing guidance](https://community.fandom.com/wiki/Help:Licensing)
identifies its default text licence as CC BY-SA 3.0; each consulted article's
search-indexed footer says CC BY-SA unless otherwise noted. No NC content is used.

Sources (every record also carries its individual source/context URL):

- [Artifacts](https://astrosplayroom.fandom.com/wiki/Artifacts): hardware names and
  broad acquisition worlds. The `ds3` label differs from guides calling it SIXAXIS;
  this discrepancy is explicit in the record. No game-authored flavor descriptions
  or media were extracted.
- [Artefacts](https://astro-bot-series.fandom.com/wiki/Artefacts): world/stage names
  and ordering. World-key joins are inferred; internal/test worlds are not mapped.
- [CPU Plaza](https://astrosplayroom.fandom.com/wiki/CPU_Plaza): world name only.
- [Puzzle Pieces](https://astrosplayroom.fandom.com/wiki/Puzzle_Pieces): concept
  context only. All 96 labels are original literal saved-key labels. No physical
  piece number, mural position, cross-game unlock rule or location is imported.
- [PlayStation Labo](https://astrosplayroom.fandom.com/wiki/PlayStation_Labo): museum
  context only. All 18 prop aliases are original readable saved-key labels, not
  wiki-backed prize identities. Their mappings remain Unknown.

Access limitation: live article/revision/API requests returned 402/403 or robots
restrictions. Search-indexed article text and licence footers were inspected;
no revision ID could be verified. `sourceVersion` records this limitation rather
than fabricating an oldid. Version 1.0.0 pins the actual selected data with manifest
SHA-256 hashes, normalized to LF by F2.

Scope: English, PPSA01325; exact structural fingerprint
`e412d790cf868baf5dd17d332fd3e025032588a34eb569e1a85487f98e55eb40`.
Game build is unknown, so the pack is build-agnostic but each alias is schema
qualified. Exactly 50 candidate artifact identities, 96 unresolved puzzle aliases,
18 unresolved prop aliases and 22 inferred world/stage aliases are supplied.
Private-save bytes are not embedded. Schema keys are evidence metadata, separate
from the wiki's licence and from gameplay verification.

Modifications: selected factual names/categories; manually joined artifact names
and world keys to readable saved identifiers; authored original uncertainty notes;
kept each puzzle prefix and ordinal verbatim instead of forcing physical 4/4 stage
groups. No screenshots, icons, maps, walkthrough prose, executable code, game
descriptions, limits, special-bot values or post-launch records are bundled.
