Modification: bounded WebP conversion, aspect ratio preserved, metadata removed.
Valisthea is 1920×756, regional screenshots at most 750px long; **137,810 bytes**
total. The [media ledger](../../../research/game-assets.json) records exact original
image URLs and input/output hashes. See [processing notes](../../../research/game-assets.source.md).
The F2 manifest pins each embedded image hash and separates world/regional rights.

Maps are reference artwork, with no saved-position mapping. Source screenshot
labels/obelisk symbols are not discovery markers from the opened save. The stored
candidate location stays in the primary map's text list without coordinates;
save-to-image alignment remains **Unknown**. Regional maps expand lazily and
contain no saved markers. Missing packs keep the stored-location list and guide.
