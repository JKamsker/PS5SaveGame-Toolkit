# Read-only overlay provenance

The matchers and descriptions are original code and prose. They embed no third-party dictionary,
guide text, artwork or save payload. Displayed property/group/option names and values come only
from the user's imported save. Mappings are restricted to the observed title, file role and shape;
Cyberpunk settings additionally require version 136. No gameplay write safety is inferred.
