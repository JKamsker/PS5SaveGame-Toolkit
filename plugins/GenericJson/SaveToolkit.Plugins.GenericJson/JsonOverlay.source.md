# Title overlay and write-adapter provenance

The matchers and descriptions are original code and prose. They embed no third-party dictionary,
guide text, artwork or save payload. Displayed property/group/option names and values come only
from the user's live imported document. Friendly labels use original word splitting of those names;
they are not verified localization or aliases. Cyberpunk bounds/defaults/choices now drive warning-labelled
v136 adapters; they are not a console-verified schema. It Takes Two flags/counters retain JSON string
storage and raw occurrence paths; changed booleans preserve the imported casing convention.
Mappings are restricted to the observed title, file role and shape;
Cyberpunk settings additionally require version 136. No gameplay write safety is inferred.

The 2026-10-28 write-enable decision is tracked in https://github.com/JKamsker/PS5SaveGame-Toolkit/issues/31.
Original adapter/preset code uses only existing values and metadata; no third-party preset, alias or
save payload is embedded. Every action parameter carries provenance and Inferred/Unknown confidence;
actions, previews and apply outcomes warn about unknown external integrity and game rejection.

Aggregate private-sample evidence rechecked 2026-10-28: all three PPSA02343 primary generations
and twins have a maximum digit-only gameplay-family counter of **67**. This original aggregate fact
sets a conservative counter ceiling of max(imported,67), not a proven score/win cap. It is not applied
to Ridge Racer numeric strings. Wrapper numeric bounds use zero and the imported value, without
importing PS1 enum/preset meanings. Text limits use imported length with a 4,096-character ceiling.
Cyberpunk has 24 recorded choice lists and 144 recorded defaults (scalar or index) among 149 options.
Float step metadata includes approximate decimal spellings such as 0.0099999997; float step alignment
is advisory because exact modulo rejects recorded defaults. Integer endpoints remain valid even when
the recorded step does not divide the min/max interval. No claim of causal in-game evidence is made.
