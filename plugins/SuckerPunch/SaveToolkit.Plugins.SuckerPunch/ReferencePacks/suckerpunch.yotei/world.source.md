# Yōtei hot spring guide — source and modifications

Dataset: `suckerpunch_yotei_world`, pack `suckerpunch.yotei` 1.0.0, retrieved 2026-10-29.
Source: [PowerPyx, Ghost of Yotei All Hot Spring Locations](https://www.powerpyx.com/ghost-of-yotei-all-hot-spring-locations/),
published 2025-10-01. Authors/holders: PowerPyx; game names and imagery belong to Sony Interactive Entertainment / Sucker Punch Productions.

16 location names and regions were transcribed; short descriptions were rewritten. No journal,
discovery, completion, reward or saved-world ID is joined. The only positioned marker is Horizon View,
at pixel (960,550) of the original 1920×1080 reference screenshot; this is not a save coordinate transform.
The remaining 15 locations stay unpositioned. All saved states and mapping confidence remain Unknown.
The text table and external guide link remain available when artwork is missing.
