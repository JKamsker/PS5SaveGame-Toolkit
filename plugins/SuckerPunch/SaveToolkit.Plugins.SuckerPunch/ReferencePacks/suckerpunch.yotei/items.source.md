# Yōtei inventory identifiers — source and modifications

Dataset: `suckerpunch_yotei_items`, pack `suckerpunch.yotei` 1.0.0, retrieved 2026-10-29.
Source: original bounded observations of the owner-supplied PPSA26344 sample generations,
tracked in [issue #22](https://github.com/JKamsker/PS5SaveGame-Toolkit/issues/22).
Author: PS5 Save Game Toolkit contributors; game identifiers belong to Sony Interactive Entertainment / Sucker Punch Productions.

48 raw named inventory identifiers are retained exactly. Category names are inferred from identifier
prefixes. Mon and Flowers have Inferred lexical mappings and symbols from the screenshot documented
in `assets.source.md`; other friendly names and ownership joins are Unknown. Descriptions are original
evidence statements, not quoted official effect text. No game save bytes are embedded.

record descriptions, field provenance, reference pickers and the Sources panel; upstream URLs are in `Info.References`.
