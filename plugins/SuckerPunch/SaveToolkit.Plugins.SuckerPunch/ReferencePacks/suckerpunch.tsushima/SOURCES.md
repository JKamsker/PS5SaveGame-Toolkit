The inventory dataset additionally uses [Arrows, oldid 31796](https://ghostfranchise.fandom.com/wiki/Arrows?oldid=31796).
Each JSON file has its own `.source.md` sidecar. `pack.json` repeats attribution per dataset;
individual records link their source revision. Wiki pages and their History links credit contributors.
[Fandom's licensing guidance](https://community.fandom.com/wiki/Help:Licensing) specifies CC BY-SA 3.0
for text unless otherwise noted; the Ghost wiki footer and API rights metadata say CC-BY-SA.

Changes: extracted Tsushima names/categories and gameplay facts; shortened descriptions and acquisition
information; removed images, markup, button glyphs and quoted game flavor text. Only the Tsushima
sections of shared franchise pages are used. The removed Archery Master's Attire is explicitly marked
historical. No game images, sample bytes or downloaded implementation code are included.

Save-key catalogs retain exact IDs and independent mapping confidence/evidence. A lexical join is
**Inferred**, not proof of ownership, equipped state, prerequisite or completion. Numbered charms and
armor slots remain raw/Unknown. The separate `wiki:` guide keys identify articles/items only: **they
are not save IDs, are not joined to save state, and must never be offered as editable replacements**.
The complete derived datasets retain CC BY-SA 3.0 share-alike, including the original mapping annotations.
