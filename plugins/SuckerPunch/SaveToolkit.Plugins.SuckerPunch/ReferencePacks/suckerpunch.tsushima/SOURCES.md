# Tsushima catalog attribution

The three records files are an original, compact index of raw identifiers observed in the
privately retained `PPSA02225` evidence manifest. The index preserves the identifiers as stored;
it does not translate names, assert ownership/equipped state, or claim capacities and write
semantics. No game assets, quotations, downloaded code, or sample bytes are included.

The research context and format leads are documented in the plugin README and the plan. The
repository is the source and attribution record for this derived index:

- Source: https://github.com/JKamsker/PS5SaveGame-Toolkit
- Author: PS5 Save Game Toolkit contributors
- Licence: Original sample-derived index; project terms
- Retrieved: 2026-10-28
- Modifications: Transcribed observed raw IDs into F2 records and grouped them by conservative
  identifier prefixes/suffixes. Grouping is a display aid and remains `Unknown` for gameplay meaning.

The Ghost Franchise Wiki pages cited in the plan are research-only and are not embedded here.
