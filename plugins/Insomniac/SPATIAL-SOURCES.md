# Spatial presentation provenance (0.6.0)

- External source: [Guides4Gamers, Rift Apart interactive map index](https://guides4gamers.com/ratchet-and-clank-rift-apart/maps/).
  Author: Guides4Gamers. Retrieved 2026-10-28. The page identifies nine regional
  maps; it states all rights reserved. **Link only.** No art, coordinates, marker
  descriptions, scripts, remote image URLs or guide-to-save identity join imported.
  Attribution is attached to MapNode.ExternalSource and in Info.References/README.
- Map labels use the existing `rift-world` reference dataset (CC0-1.0, pinned
  Neptuwunium/Rivet schema; see its data.source.md and pack.json). Marker IDs are
  actual stored bit identities. Every marker remains Unknown; its description and
  linked scalar expose exact set/clear storage, including reserved bits. No
  coordinates or coordinate permission assertion is present.
- Graphs are original toolkit presentations of sixteen measured ModGrid row masks
  per supported fixed-mask weapon record. Schema field names derive from the same
  pinned CC0 schema. All nodes have Unknown gameplay states; there are no costs or
  prerequisite edges. Browser layout is schematic, not an in-game upgrade-grid
  transform. Exact scalar masks and field targets supply the text alternative.
- No upstream parser implementation, game icon or unlicensed visual data was copied.
  Physical pickup locations, node dependencies/costs and fog transforms require
  the controlled experiments in OWNER-CAPTURES.md and owner issue #31.
