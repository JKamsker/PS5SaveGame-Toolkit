`images.provenance.json` records every source page/revision, original file name,
CDN URL, image timestamp and wiki SHA-1, retrieved-response SHA-256, processed
SHA-256, dimensions and exact size. CDN responses can be WebP despite PNG/JPEG
URL extensions: headers and Pillow decoding were validated before conversion.
No downloaded source code was executed. Image processing ran with Python `-I`
in `%TEMP%/insomniac-assets`; only processed images and provenance were copied.

- 20 weapon icons: Rift Apart-specific icons selected for returning weapons.
- 19 upgraded-form render thumbnails: second, explicitly named form from each
  weapon page. RYNO ∞ has no distinct supplied image and retains a text fallback.
- 16 full-set armour previews: 51 records across 17 set candidates. Preorder
  Carbonox shares the Carbonox Advanced image, as the wiki documents identical
  appearance. These are **set thumbnails, not individual slot icons**.
- Emperor/Reaver internal aliases remain unconfirmed and have no assigned image.

All images fit within **64 × 64**, preserve the full aspect/extent, and use WebP
quality 85, method 6. Identical Carbonox images share one resource.
Black silhouette weapon icons have a pale opaque backing for legibility in both
light and dark themes; original extent and proportions remain unchanged. There are
**55 unique icons/previews, 74,526 bytes**. `assetId` names are local to the same
F2 pack. The framework qualifies IDs, validates content types/hashes/dimensions,
loads once and shares bytes across pinned document contexts; plugin code does
not decode, copy, download or reload image files. F8 image cells materialize on
requested pages; missing catalogues retain raw IDs and text fallbacks.

Descriptions are original concise **synopses**, not verbatim menu quotations.
There are 20 base weapon, 20 upgraded-form and 51 piece synopses, derived from the
pinned menu transcript. Existing alias/ownership/collection warnings remain.
No node-level upgrade icons or prerequisite/cost mappings are invented: ModGrid
bit identities are still uncalibrated. Upgraded forms occupy a separate labelled
reference catalogue and are never presented as this save's unlocked weapon level.
