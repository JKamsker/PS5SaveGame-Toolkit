the additional table. Minecraft Wiki access rows have been removed because they no longer appear

## Maintaining the register

Update the README exclusion decision and its central row together. Preserve the exact source,
revision, terms, disposition, alternative and unblock evidence; rebase relative links here.
Update the summary counts as well. Run `python docs/tests/test_documentation.py` to check both
directions, additional source evidence and the counts. The check performs no network or file writes.
Upstream issue states are checked separately with `gh issue view <url>` or `gh api`.

Keep publisher/community material distinct. Missing data, access failures and uncertain native joins
are evidence gaps. Refuse only specific GPL-2.0-only code or NC/no-redistribution material, recording
the same refusal in both places. Missing licences and rights-reserved publisher/site material follow
the owner decisions above; applicable notices and share-alike terms remain in force. Unlicensed
implementations are independently reimplemented from documented behaviour with source credit.

Follow the [owner checklist](OWNER_CHECKLIST.md) for native captures and console validation.
Track further source decisions on [#37](https://github.com/JKamsker/PS5SaveGame-Toolkit/issues/37)
or the linked plugin issue without posting private saves/game dumps.
