# Licence exclusions and missing rights evidence

## Owner policy — 2026-10-28

**No licence is not a blocker.** Import unlicensed community data and facts (ID tables, names,
offsets, hash tables, format layouts and community coordinate facts) with full attribution. Use
`No licence published; reused with attribution per owner decision 2026-10-28` in the imported data's
licence field. This includes community sources previously excluded solely for an all-rights-reserved
notice. Reimplement code from unlicensed repositories from documented behaviour, crediting the source.
This records the owner's reuse decision; it does not claim that an upstream licence was published.

The only remaining licence-based refusal reasons are **GPL-2.0-only code; NC or no-redistribution
terms; and proprietary game assets: publisher art, icons, screenshots and text extracted from the
game**. Mixed sources are assessed per material: community facts may be imported while publisher
assets remain refused. No reviewed record identifies a specific GPL-2.0-only source refusal.
Every remaining refusal still needs a row here and in the plugin README's `## Licence exclusions`
table, as required by [plugin-guide rule 9](PLUGIN_GUIDE.md#hard-rules).

## Maintaining the register

Update source rows and plugin README tables when an import/reimplementation lands or a remaining
refusal changes. Record source/revision, attribution, published terms or the exact owner-decision
licence field, material imported and implementation approach. Keep unblocked rows for history and
replace `import in progress` with a verified delivery reference when complete. Do not claim that the
owner decision supplies an upstream licence or permits the remaining refused material.

An owner can supply matching community datasets/captures without obtaining a new licence solely
because none was published. For actual NC/no-redistribution, GPL-2.0-only code or publisher-asset
refusals, seek compatible permission or use an alternative permitted source. Reimplement unlicensed
code from documented behaviour with source credit rather than requiring an implementation licence.

Research-only mentions of permitted code/data are not exclusions: examples include GPL-3.0
WolvenKit/KingdomSaveEditor, MIT PlayStation-PS1HD/Nex/neuro-pragmata and the adopted CC BY-SA wiki
catalogues. Insomniac's EUPL/GPL research notes record independent implementation, not an established
licence refusal under the owner's categories. Access errors, unsupported platforms, missing save
identities and incomplete dependency writers remain separate technical/evidence limits.

Follow the [owner checklist](OWNER_CHECKLIST.md) for native captures and console validation and
report a resolved rights entry on [#37](https://github.com/JKamsker/PS5SaveGame-Toolkit/issues/37)
or its linked plugin issue without posting private game dumps.
