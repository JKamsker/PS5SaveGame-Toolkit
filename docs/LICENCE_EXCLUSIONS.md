## Owner policy — 2026-10-28

**No licence is not a blocker.** Unlicensed community facts, including IDs, names, offsets,
hash tables, format layouts and coordinates, are usable with full attribution. Record exactly:
`No licence published; reused with attribution per owner decision 2026-10-28`.
Reimplement unlicensed code from documented behaviour with source credit; do not copy its
implementation. This is the owner's reuse decision, not an upstream licence grant.

## Owner policy — 2026-10-29

**"All rights reserved" sites and publisher game assets are usable with attribution.** This
includes art, icons, screenshots and extracted game text. Name the source, rights holder and
revision/retrieval date in source sidecars, README tables, plugin references and UI provenance,
as required by [plugin-guide rule 9](PLUGIN_GUIDE.md#hard-rules). Record exactly:
`Rights reserved by <holder>; used with attribution per owner decision 2026-10-29`.
Retain separately applicable community licences/notices and keep embedded binary packs bounded.

The only remaining licence-based refusal reasons are **GPL-2.0-only code and explicit NC or
no-redistribution terms**. Publisher ownership or a missing licence alone is not a refusal.
The reviewed files identify no specific GPL-2.0-only source refusal; generic unverified
README language is recorded below without inventing an upstream licence.

  not necessarily the import date. Broader missing-pack rows explicitly describe partial coverage.
- **Still refused** identifies specific NC/no-redistribution terms; publisher art is separated

- **Not used** means no import from that source/material: an alternative sufficed, applicable
  data/access/native joins were unavailable, or the implementation did not need it. Research-only
  citations can remain. This is not a licence refusal.

## Maintaining the register

Update source decisions when imports or alternative selections land, retaining the source/revision,
attribution, published terms or exact owner-decision field and the implementation approach.
Verify against the intended `main` snapshot, including local merged work when it has not been pushed.
Do not turn a missing build-matched pack, blocked page, uncertain native join or absent console
capture into a licence refusal, or describe a policy decision as an upstream licence grant.

For an actual NC/no-redistribution or GPL-2.0-only restriction, obtain a compatible source-specific
grant or choose another source. Unlicensed implementations must still be independently reimplemented
from documented behaviour with credit. MIT, GPL-3.0, GPL-2.0-or-later and CC BY/CC BY-SA sources are
not refused merely for copyleft/share-alike; retain their notices and applicable data terms.

The historical Gearbox `bl3data`/`wldata` NC claims lack exact supporting terms in the old register;
the current pinned README records no published export licence and no payload import. Unspecified
FinalFantasy7 NC datamines, TalesOfArise GPL-2.0-only/commercial sources and Witcher3 standalone XML
mirrors likewise cannot be verified as named restrictive sources. Their rows state the limitation
instead of fabricating refusals, source URLs or revisions. The three Minecraft Wiki access rows
retain their recorded 403/no-revision limitation; no completed wiki import is claimed.

Follow the [owner checklist](OWNER_CHECKLIST.md) for native captures and console validation.
Track further source decisions on [#37](https://github.com/JKamsker/PS5SaveGame-Toolkit/issues/37)
or the linked plugin issue without posting private saves/game dumps.
