# v0.1.0-rc.2 highlights

This prerelease builds on rc.1 with robustness, performance and editor improvements from the [review programme (#40)](https://github.com/JKamsker/PS5SaveGame-Toolkit/issues/40).
**Edits remain experimental and are not console-validated. Keep an untouched backup.**

## Safer saves

- All **17 game/format plugins** received malformed-input reviews and corruption/boundary
  coverage; some reviews found no defects. New checks reject invalid child links,
  overlapping sections, malformed primitives and incomplete compressed streams, with
  allocation limits checked earlier. Examples: [Cyberpunk](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/fc55788),
  [Baldur's Gate 3](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/05649e4),
  [Atomic Heart](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/98dae57),
  [Elden Ring](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/2f13734).
- Import verifies ZIP checksums, preserves nested layouts, case-distinct file generations
  and legacy filenames, and cleans up partial imports after failures. Interrupted uploads
  report useful errors. ([b42ff23](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/b42ff23),
  [dc06325](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/dc06325))
- Shared codecs reject truncated Kraken interval data and bound SQLite integrity-check work.
  ([c12d514](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/c12d514))
- Clearer write limits, confidence labels and warnings distinguish stored-byte evidence
  from unproven gameplay effects. All game/format plugins remain **Experimental**;
  supported schemas and read-only exceptions are listed in the
  [user guide](https://github.com/JKamsker/PS5SaveGame-Toolkit/blob/main/docs/USER_GUIDE.md#supported-titles-and-write-limits).
  ([6bb99b1](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/6bb99b1), #40)

## New edit workflows

Fifteen reviewed workflows from the [edit-coverage analysis](https://github.com/JKamsker/PS5SaveGame-Toolkit/blob/main/docs/EDIT_COVERAGE.md)
compose already-enabled writes. Each has a preview, cancel, atomic apply and one-step undo/redo,
keeps existing per-field limits and skips locked/unknown rows with a reason. All remain
**Experimental**; console effects are unvalidated ([#31](https://github.com/JKamsker/PS5SaveGame-Toolkit/issues/31)).
"Restore imported" means the value this workspace opened with; higher values are left unchanged.

- **Final Fantasy VII Remake/Rebirth:** recover selected characters' current HP/MP, batch character
  levels with matching XP, and a stored play-time setter bounded by the opening value. [ec30f75](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/ec30f75), [77149d2](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/77149d2)
- **Borderlands 3 / Wonderlands:** match selected gear to the character level, restore imported ammo,
  batch favorite/junk marks. [319be9e](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/319be9e)
- **Final Fantasy XVI:** named Gil/AP/Renown balance previews; restore imported ordinary stacks. [3cabf91](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/3cabf91)
- **Cyberpunk 2077:** batch unspent attribute/perk/relic point targets. [66df12b](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/66df12b)
- **The Witcher 3:** batch counts of existing ordinary Gwent cards. [baab91d](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/baab91d)
- **Restore imported values:** Tales of Arise consumables [dbab779](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/dbab779), Atomic Heart amounts [fa7284e](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/fa7284e),
  Ghost of Tsushima ammo (both copies) [a422395](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/a422395), ASTRO's PLAYROOM ownership flags [98054d0](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/98054d0),
  Pragmata quantities [bf74ec6](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/bf74ec6).
- **Tales of Arise:** party CP current/max is shown read-only (Inferred). [d10cfb6](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/d10cfb6)
- Review fixes before release: FF7 level undo restores the exact opening level/XP pair, and FF7,
  Tsushima and Tales of Arise table actions act only on the selected rows. [77149d2](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/77149d2),
  [359faad](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/359faad), [533feef](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/533feef)
- Ghost of Yōtei quantity restoration was investigated and **deferred**: the samples cannot establish
  exact checksum coverage. [50eba10](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/50eba10)

## Faster

Figures compare individual review revisions; later safety checks can add work. These
are local Release-build results, not guarantees. MB/kB are decimal **managed allocations
per operation**, not process memory. Timings exclude browser rendering; linked reviews
record their setup and exclusions.

- **Cyberpunk 2077:** warm open + first view **113 → 55 ms**, allocations **61.4 → 26.2 MB**.
  ([e3aca9a](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/e3aca9a))
- **Baldur's Gate 3:** first view, including initial live collection pages, **234 → 138 MB**;
  twenty subsequent live pages **51.0 → 0.90 MB**.
  ([bece1f3](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/bece1f3))
- **Borderlands 3 / Wonderlands:** fallback initialization + first root view allocates
  **78% / 85% less**. Deferred catalogs still load when inspected; their eventual cost
  is not eliminated. ([d05ad1c](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/d05ad1c))
- **Pragmata:** repeated ten-row pages of the 6,988-row retail evidence collection drop
  **39.9 MB → 19.2 kB** after indexing; first-view allocations **54.7 → 37.7 MB**.
  ([8800ea0](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/8800ea0))
- **Elden Ring:** main-catalog no-match search **27.5 MB → 2.4 kB**; first regulation
  expansion **84.5 → 46.3 MB**. ([e461bd8](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/e461bd8))
- **Final Fantasy XVI:** largest-sample open + first view **4.4 → 2.5 ms**, **7.2 → 3.1 MB**.
  ([cf80915](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/cf80915))
- **Tales of Arise:** deep 20-word evidence page **4.26 MB → 20.1 kB**. ([3e777c6](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/3e777c6))
- **Generic JSON stress case:** a synthetic 50,000-member wrapper opens with its first
  view in **4.63 s → 78 ms**; this is not a measured gameplay-save speedup.
  ([7f543bb](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/7f543bb))
- **Shared collection helper:** 1,000-row paging **273 → 41 kB**, about **85% less**.
  **Kraken codec:** a warmed 14-stream Atomic Heart batch drops **10.47 → 0.63 MB**
  with caller-owned output and a reused workspace; Atomic Heart now adopts that path.
  Setup/retained pool memory is excluded. ([ef214e2](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/ef214e2),
  [3d1b689](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/3d1b689),
  [72cd997](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/72cd997))

## Editor

- The change review lists edits inside large paged tables with labels and original/current
  values, warns when coverage is partial instead of claiming "no changes", jumps to the changed
  row and reverts individual entries. [33ed784](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/33ed784), [520ee2f](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/520ee2f)
- Exports of unrecognized layouts keep their imported paths instead of gaining an `UNKNOWN/`
  prefix. [6ab1b74](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/6ab1b74)
- Reference cells and action parameters fetch catalog records in field-aware batches: the FF7
  Rebirth browse flow drops from **162 to 4** reference requests. ([faab16d](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/faab16d))
- Pragmata's change review lists each edited quantity once instead of twice (**500 → 250**
  entries) via SDK-02 field metadata. ([a22ee64](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/a22ee64))
- Workspace export streams through a self-deleting temporary file instead of memory.
  [b6632de](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/b6632de)
- Keyboard navigation, focus recovery, named controls, live loading/error announcements
  and validation states improve accessibility.
  ([0f43762](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/0f43762))
- Failed reads and stale responses preserve drafts and the active editor; clearer
  ProblemDetails messages and explicit retries help recover from errors.
  ([3c42e23](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/3c42e23))
- Ordered edits/history, duplicate-submit guards and navigation lifetimes prevent older
  responses overwriting newer work. Export waits for accepted writes; backend fixes
  prevent plugin-switch edit loss and cleanup during active requests.
  ([31e2678](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/31e2678),
  [97c7ec5](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/97c7ec5))
- More legible confidence/warning badges, aligned numeric tables and responsive light/dark
  layouts accompany a [user guide](https://github.com/JKamsker/PS5SaveGame-Toolkit/blob/main/docs/USER_GUIDE.md)
  covering download verification, editing, export and troubleshooting.
  ([5951469](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/5951469),
  [6bb99b1](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/6bb99b1))

- New additive SDK contracts: field metadata with canonical/derived binding policy (SDK-02,
  [de78531](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/de78531)), shared bounded embedded reference-pack decoding (SDK-03, [1a348ab](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/1a348ab)),
  document-group member identity adapters/routing (SDK-04, [f869910](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/f869910)), exact icon
  alt-text/availability options (SDK-05, [0e31467](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/0e31467)) and bounded paged-table semantic
  review (SDK-01). FF7, FF16, Ragnarök, Baldur's Gate 3 and Tales of Arise already adopt
  SDK-03/SDK-05 with unchanged view fingerprints.
- Inherited conformance now includes deterministic mutation fuzzing, with a nightly deep run.
  ([69e2f47](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/69e2f47))
- Shared helpers cover in-memory collections, action-plan revalidation, bounded binary
  cursors/FStrings, IEEE CRC32, catalog traversal, icons and reference inspection.
  Storage-only field registration and cached pinned-catalog selection reduce overhead.
  ([8ff24d7](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/8ff24d7),
  [6ba497b](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/6ba497b))
- [docs/API.md](https://github.com/JKamsker/PS5SaveGame-Toolkit/blob/main/docs/API.md)
  documents all 38 method/route pairs, revisions, errors and downloads, with endpoint
  coverage checks; the web client adds typed catalog record-detail access.
  ([36eea58](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/36eea58),

- The [SDK request inventory](https://github.com/JKamsker/PS5SaveGame-Toolkit/blob/main/docs/SDK_REQUESTS.md)
  separates delivered helpers from remaining contracts. The scaffold/walkthrough includes

## Known limitations

- Successful export/integrity checks do **not** establish console acceptance. Controlled
  owner captures, no-action controls and spare-slot load/resave/reload checks remain
  deferred in [#31](https://github.com/JKamsker/PS5SaveGame-Toolkit/issues/31); unknown signatures,
  dependencies and unsupported builds still limit edits.
- The SDK inventory has **4 open items**: a shared lossless JSON substrate, persisted presets,
  canonical field-reference presentation, and the `param.sfo` subtitle synchronization policy.
  See the [backlog and workarounds](https://github.com/JKamsker/PS5SaveGame-Toolkit/blob/main/docs/SDK_REQUESTS.md).
