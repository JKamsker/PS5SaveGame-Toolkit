# v0.1.0-rc.3 highlights

This prerelease builds on rc.2 with lower reference-pack memory use, more reliable editing
and validation, and additional read-only game data from the
[review programme (#40)](https://github.com/JKamsker/PS5SaveGame-Toolkit/issues/40).
**Edits remain experimental and are not console-validated. Keep an untouched backup.**

## Safer saves

- Import pairs backup twins only inside recognized console save directories, preserving
  unrelated loose `SAVE` files. Cancellation now reaches import, export, semantic review
  and queries, with cleanup and rollback coverage.
  ([c613c531](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/c613c531),
  [73b2cc00](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/73b2cc00))
- Gearbox and XorJson reject malformed or foreign member keys instead of silently accepting
  incomplete selections. Their shared SDK-04 adapters retain characterized routing and
  protocol behavior.
  ([2ba40972](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/2ba40972),
  [ce0740c2](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/ce0740c2),
  [d92b07a4](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/d92b07a4))
- Reference-pack decoding rejects resource names that collide after normalization and
  duplicate JSON properties, avoiding silent data replacement.
  ([b96a2686](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/b96a2686))
- All 17 plugins received a confidence-label and write-warning review. Pragmata places
  write warnings beside editable fields, and a shared advisory conformance check helps
  identify misleading labels.
  ([06866f0e](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/06866f0e))
- Culture-independent parsing, formatting and comparison keep wire values and identities
  consistent across locales; web fixes cover exact-number handling and enum controls.
  ([abca056a](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/abca056a))

## Faster

Figures are local Release measurements at the linked review revisions, with setup and
exclusions documented in the
[performance guide](https://github.com/JKamsker/PS5SaveGame-Toolkit/blob/main/docs/PERFORMANCE.md).
They are not guarantees for every machine or save.

- Lazy, shared embedded reference data reduces idle retained managed memory for all
  40 packs from **152.14 to 3.00 MiB**. Materializing every pack retains **92.62 MiB**
  versus **153.29 MiB** before. Construction still validates the packs; first access
  pays the deferred materialization cost.
  ([de71df0c](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/de71df0c))
- Plugin discovery reuses assembly-name metadata, reducing measured discovery allocations.
  Bounded change review uses exact endpoint queries where available and reports partial
  coverage when limits are reached.
  ([9be32cd8](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/9be32cd8),
  [0ccfebbf](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/0ccfebbf))
- Splitting the document editor reduces the workspace chunk from **45.49 to 5.13 kB gzip**;
  the editor loads separately. CI enforces initial JavaScript/CSS and per-chunk budgets.
  ([22407324](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/22407324))
- An opt-in BenchmarkDotNet suite and startup observations provide repeatable baselines
  without adding timing-sensitive CI gates.
  ([69e7274c](https://github.com/JKamsker/PS5SaveGame-Toolkit/commit/69e7274c))

## Known limitations

- Successful export and integrity checks do not establish console acceptance. Controlled
  owner captures and spare-slot load/resave/reload checks remain in
  [#31](https://github.com/JKamsker/PS5SaveGame-Toolkit/issues/31). Unknown signatures,
  dependencies and unsupported builds continue to limit edits.
- The SDK inventory retains **4 open items**: shared lossless JSON, persisted presets,
  canonical field-reference presentation and the `param.sfo` subtitle synchronization
  policy. See the [backlog and workarounds](https://github.com/JKamsker/PS5SaveGame-Toolkit/blob/main/docs/SDK_REQUESTS.md).
- Lazy reference loading defers some work to first access, and change review can remain
  partial on views without complete query support. The UI reports these limits.

## Checksums

The release pipeline publishes four platform archives, adjacent `.sha256` files and
`SHA256SUMS`. Verify downloads with `sha256sum --check SHA256SUMS` on Linux,
`shasum -a 256 --check SHA256SUMS` on macOS, or `Get-FileHash -Algorithm SHA256` on Windows.
The manifest covers the archives; checksum values are supplied by the packaging workflow.
