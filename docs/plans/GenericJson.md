# GenericJson — improvement plan

> **Historical planning snapshot — 2026-10-28.** The baseline, proposed work, test counts and
> policy restrictions below describe that research round, not current implementation or permissions.
> See [current plugin status](../PLUGINS.md), the linked plugin README,
> [delivered framework features](ROADMAP.md) and [current policy](../PLUGIN_GUIDE.md#hard-rules).

## Summary

GenericJson (`format.json`) is already a careful UTF-8 token editor: it preserves untouched bytes, supports bounded lazy navigation and edits primitive values, but has no semantic overlays or structural editing. A substantially better product combines an exact JSON workbench with curated Cyberpunk settings, Ridge Racer emulator options and **It Takes Two (PPSA02343)** chapter/minigame views. The strongest immediate opportunity is Cyberpunk's self-describing settings: the actual PS5 file supplies option types, ranges, defaults and many enum lists. The top three blockers are **exact-number/nullable support across the editing protocol**, **reversible structural edits with stable identity and cache invalidation**, and **controlled PS5 evidence for semantic dependencies, ranges and in-game acceptance**. Build read-only interpretation first, then existing-value edits, and only later insertion/deletion and progression presets; a generic syntax editor must not imply gameplay compatibility.

### Integrity / crypto

- [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259) (2017) defines grammar and interoperability limits, not a checksum, encryption or game acceptance rule. These selected files parse as complete UTF-8 JSON with no additional visible wrapper. There is **no demonstrated embedded hash repair requirement**, but external relationships are Unknown. Do not invent checksums, normalize duplicates or canonicalize whole files. Standards are format references; any extracted RFC code components have their own notice requirements.
- [RFC 6901](https://www.rfc-editor.org/rfc/rfc6901) / [RFC 6902](https://www.rfc-editor.org/rfc/rfc6902) (2013) define escaped pointers and ordered add/remove/replace/move/test operations. Pointer lookup is undefined for duplicate member names; RFC-style pointers must be display/export paths only when unambiguous. Internal edits need occurrence-aware node IDs, original-version preconditions and an undo representation preserving token bytes. Use a restricted, documented operation model rather than claiming full JSON Patch compliance with duplicates.
- [JSON Schema 2020-12](https://json-schema.org/specification), [annotations](https://json-schema.org/understanding-json-schema/reference/annotations) and [null](https://json-schema.org/understanding-json-schema/reference/null) separate type/range validation, descriptive annotations and missing versus null. `default` is not automatic insertion or proof of game safety. Implement an explicitly supported local schema subset first; no remote `$ref` resolution inside plugins, no silent default filling, no unknown-property stripping.
- **Cyberpunk dependency:** `value/index`, defaults and dynamic platform options need version-aware validation. The actual 24 explicit enum pairs agree, supporting an atomic paired setter, but causal authority of `value` versus `index` is not proven. Keep metadata summaries read-only in the curated overlay; modifying a displayed level/playtime field is not editing `sav.dat`. `user.gls`, gameplay container integrity and PS5 system signing are out of scope.
- **It Takes Two dependency:** chapter, furthest unlock, last checkpoint, minigame discovery/play flags and story flags may be coupled. Sparse key absence does not equal a proven false value; string booleans cannot become JSON booleans. Keys/signatures are not the blocker for the observed inner file; dependency semantics and console acceptance are. No checkpoint preset or “unlock all” is safe solely because the output reparses.
- **Ridge Racer dependency:** JSON options and gameplay DATA.BIN are separate. No wrapper-option checksum or enum table was established; do not import PSP savedata encryption/integrity or console signing into the JSON writer. Preserve unrelated payloads and system metadata, relying on the existing export/save-manager workflow.

## Vision

- **Overview:** identify format and matched schema/title/version, state exactly which meanings are Verified/Inferred/Unknown, show original/current byte size and validation status. Unsupported variants retain raw access without silently applying a neighboring platform's schema.
- **Settings / Progress:** Cyberpunk groups become readable controller, accessibility, audio, display and gameplay forms with file-derived bounds and enum choices; reset one setting/group only to recorded, validated defaults. It Takes Two shows May/Cody minigame discovery/play/scores, chapter/checkpoint relationships and a chapter checklist. Ridge Racer shows conservative graphics/controller/emulator groupings with unknown enums explicitly raw.
- **JSON workbench:** exact-number text controls, nullable controls distinct from missing properties/empty strings, literal versus decoded string display, occurrence-aware breadcrumbs, search across collapsed content, filtered homogeneous tables and an always-available raw token view. Generic values are not automatically coerced based on names.
- **Changes:** original/current semantic and raw-token diff, changed-only filters, jump to field, revert one change/group, show type/structure changes and paired updates, and export a local review report with sensitive values excluded. Diff must distinguish a numeric lexeme from a numeric-looking JSON string.
- **Advanced structure:** previewed append/insert/remove/move/duplicate for arrays and authorized optional object members; one atomic, undoable transaction with schema validation. Defaults/templates come from a matching schema or explicit user choice, never guessed from the first row. Preserve existing unknown members, ordering, duplicate occurrences and untouched byte spelling.
- **Bulk actions/presets:** value-only recorded-default resets first. Later, evidence-backed minigame score resets or chapter presets with an exact change preview and dependent-field validation. No “max everything,” trophy guarantee, inventory fabrication or copied PS1 visual preset. Text-only/placeholder icons are useful deliverables; artwork is optional.

## Phased plan

### Phase 1 — evidence baseline and read-only semantic views (M)

- [ ] Add PPSA02343 to future JSON conformance/sample selection by content, including `.sav` and every archive occurrence/twin; record identity and root nesting in authorized docs.
- [ ] Add plugin-local immutable overlay matchers using title + file role + structure + version, with generic fallback. Keep generic Info.Games empty; avoid claiming all regions/versions from one ID.
- [ ] Build Cyberpunk grouped read-only option forms, It Takes Two chapter/minigame tables and Ridge Racer option groups using existing nodes; preserve raw JSON access. Use original labels for unknown aliases.
- [ ] Add occurrence-aware displayed paths and a lazy synthetic fixture baseline for later edits. Separate format certainty from gameplay confidence.
- Evidence needed: measured corpus above, screenshots/labels from owners; no new framework work blocks a basic read-only overlay. Risk: false schema match, ambiguous aliases, metadata confused with live state.
- Exit: all matched variants show accurate read-only summaries, unknown variants fall back; no new writes enabled from naming alone.

### Phase 2 — exact existing-value editing, nullable controls and preservation (L)

- [ ] Carry JSON numeric lexemes as strings end-to-end, separately typed from text. Preserve arbitrary-length mantissas/exponents within documented resource limits; never materialize `1e1000000` as a million-digit number to validate grammar.
- [ ] Add schema-authorized nullable/union fields and explicit set-null/restore-value controls; retain current unknown-type defaults until user selection. Distinguish missing member, null and empty string.
- [ ] Preserve original raw spelling when unchanged/reverted, including `-0`, exponents, escapes and BOM. Permit multiline JSON strings through suitable TextSpec without changing their stored escaping rules.
- [ ] Gate changes through authoritative server validation and meaningful API/browser/undo tests; allow exact numeric TextSpec + plugin validation as a temporary limited workaround if protocol changes are delayed.
- Evidence needed: synthetic numeric/null/Unicode corpus; current samples validate preservation but do not contain every required edge. Risk: coercion through double in one layer, rounding hidden by value equality, nullable cache/spec mismatch.
- Exit: long integers/decimals, extreme exponents and null survive edit/export/reopen/undo without numeric loss; invalid batches leave bytes unchanged.

### Phase 3 — useful, validated existing-value overlays (M–L)

- [ ] Enable safe Cyberpunk scalar setting edits using recorded bounds; versioned adapters update enum value/index atomically and report derived changes. Keep dynamic lists with missing choices raw/read-only until verified.
- [ ] Implement plugin-local schema bindings that expose a bool/integer/enum while preserving string storage for It Takes Two. Preserve field-specific casing; do not rewrite identity/EULA/telemetry or unknown flags through gameplay actions.
- [ ] Enable only confirmed Ridge Racer option edits; show raw values for unknown filter/upscale enums. Provide reset-to-imported-value immediately; recorded game-default resets only where the source and dependent fields are known.
- [ ] Add original/current diff for all fields, including unexpanded lazy content, and full-tree key/value search with bounded results and jump-to-path. Existing TableNode can serve an interim paged/limited results view.
- Evidence needed: CP before/after enum/scalar saves, ITT discovery/play/score pairs, RR one-setting changes and console observations. Risk: game overwrites settings, string value normalization, defaults unsuitable for platform.
- Exit: per-feature effect confirmed on PS5, unrelated tokens unchanged, one undo restores every paired value; keep maturity Experimental until owner approval.

### Phase 4 — reversible generic structural editing (L)

- [ ] Extend ordered token model with container end/trivia/separator spans and immutable session node identities. Existing node IDs survive insertion/removal before them; newly inserted nodes get fresh IDs; undo restores removed identity and exact original bytes.
- [ ] Define structural transactions with preconditions, atomic validation, inverse payloads and bounded history. Sequence punctuation edits against the evolving model; do not concatenate overlapping independent byte edit lists.
- [ ] Implement array insert/remove first, then move/duplicate and optional object-member add/remove/rename. Reject ambiguous duplicate-key schema operations; raw occurrence selection remains explicit.
- [ ] Extend Core history and binding/index lifecycle, version every structural request, clear stale IDs/specs/actions and lazy caches, and keep selection/focus sane. Do not ship routine structure edits as non-undoable actions that erase history.
- [ ] Add schema-aware templates, min/max item limits and preview controls; unknown-schema structural edits remain advanced and explicitly lack game-safety claims. Do not insert game profile keys merely because absent means “probably false.”
- Evidence needed: synthetic mixed arrays, empty/singleton containers, adjacent removals, duplicate keys, nested edits and max-resource fixtures. Risk: punctuation corruption, identity reassignment and stale-client writes.
- Exit: structure + value edit + undo/redo + export preserve identity, all unaffected byte spans and exact original bytes after complete undo.

### Phase 5 — title presets and complete reference packs (L; conditional)

- [ ] Complete the 25-minigame display/alias catalogue and chapter/checkpoint graph using game-generated data plus human verification; show missing/unknown distinctly. Keep world-story puzzle flags separate from minigame availability.
- [ ] Offer validated progression/minigame presets only after dependency matrices and console tests; start with edits to existing keys before introducing missing keys. Presets carry schema/version, source and supported title IDs.
- [ ] Add offline owner-supplied localization/icon packs if worthwhile; require explicit rights/provenance, stable ID mapping and placeholder fallbacks. No game asset pack is a prerequisite for a useful editor.
- [ ] Coordinate any future Cyberpunk companion changes with its gameplay plugin; reuse existing multi-file output and export-conflict protections. Do not add car/inventory editing here without a separately proven format adapter.
- Evidence needed: complete checkpoint corpus, known complete/incomplete profiles, re-export after preset load, permitted reference data. Risk: softlocks, false completion, patch-specific keys and incompatible asset licensing.
- Exit: every preset lists tested effects and dependencies; unsupported combinations are rejected, and no unsupported platform compatibility is advertised.

## Acceptance criteria

- [ ] Preserve current content detection, UTF-8 strictness, duplicate occurrences, BOM and bounded parsing/views; binary `.sav` siblings never become JSON because of title/filename.
- [ ] Every supplied JSON occurrence/twin, including all three PPSA02343 `.sav` generations, opens through matching coverage and has byte-identical no-op serialization. Tests skip missing private samples; no extracted saves are committed.
- [ ] Mark observations as Verified/Inferred/Unknown separately from in-game compatibility; show generic fallback for unknown schema/version instead of inferred defaults or constraints.
- [ ] Numeric edit/export/API/browser/undo tests include Int128 boundaries, >128-bit integers, >17-digit decimals, tiny/huge exponents, negative zero and original spelling restoration; no hidden double conversion or infinity/underflow loss.
- [ ] Null, missing and empty string have distinct behavior; union/type changes require allowed choices and authoritative validation. Multiline/Unicode strings preserve unrelated bytes and reject invalid surrogate edits.
- [ ] Cyberpunk uses group plus option name/occurrence, honors actual ranges, preserves all unknown metadata and pairs enum value/index in one validated undo batch. Dynamic-list gaps remain explicit.
- [ ] It Takes Two preserves string storage and per-field boolean spelling; no raw numeric conversion, missing-key insertion or chapter/checkpoint mutation is justified solely by a readable key name.
- [ ] Ridge Racer separates emulator options from DATA.BIN, and no PS1 preset/enum transfers without a matched PS5 before/after test.
- [ ] Every changed output reparses; all unrelated value tokens and unaffected byte spans remain identical. A full undo restores original bytes, not merely equivalent JSON.
- [ ] Structural tests cover first/middle/last/adjacent/all removals, empty containers, nested moves, duplicate keys, retained node IDs, deleted-node undo and stale-client rejection; invalid operations change nothing.
- [ ] Search/diff include collapsed content within bounded paging; views still emit at most 128 nodes per lazy expansion; deleted fields/actions cannot remain editable through cached IDs.
- [ ] Search filters reflect live values; diff preserves the original baseline across refetch and distinguishes lexical-number edits from string edits and paired updates.
- [ ] Each semantic feature has a controlled PS5 load/restart/resave/re-export record before being described as verified in-game. Only the human owner changes maturity to Stable.
- [ ] Reference packs document revision, coverage, stored-ID mapping, sources and permissions. Retain MIT/ISC notices for adapted code; no GPL/unknown-license implementation or publisher artwork is silently embedded.
- [ ] Future implementation stays within assigned plugin scope and uses separately assigned framework/UI tasks for listed blockers; maintain small composed C# files and pass conformance plus focused regression checks when implementation is authorized.

## Open questions & risks

- Does Cyberpunk load by enum `value`, `index` or both, and does its settings version correspond to a stable schema? Current file consistency is evidence for a paired editor, not proof of causal semantics. Hidden/debug groups and duplicate setting names require explicit treatment.
- What creates the three It Takes Two snapshots, and which are before/after one another? Their order is not a trustworthy timeline; fewer members may mean a different history, reset or partial profile. Do not infer progression monotonically from size.
- Are It Takes Two boolean spelling and missing flags semantically significant, and which counters are scores, lap times, wins or story-state ordinals? A casing-preserving adapter is necessary but not sufficient for safe edits.
- Which chapter/checkpoint/story flags must move together to permit Continue, Chapter Select and minigame replay? A full map graph and console testing are required before “unlock all”; trophy behavior is not promised.
- Do other title regions/patches use the same nested Profile schema? Only PPSA02343 was byte-checked. PC flat-profile compatibility supports research reuse, not file conversion or broad platform claims.
- Which Sony PSP-wrapper version generated these Ridge Racer settings, and do numeric enums share any PS1HD meaning? Names alone cannot establish filter/AA/upscale domains or safe shader parameters.
- Exact-number editing preserves JSON syntax/value faithfully but cannot make a game's finite numeric reader accept arbitrary magnitudes. Schema-specific bounds remain necessary even after protocol precision is fixed.
- Duplicate keys are intentionally preserved yet undermine standard pointers, schema object models and conventional diffs. Use occurrence-aware identity and decline ambiguous semantic matching; do not silently deduplicate.
- Structural change support touches protocol, server history, binding/index lifecycle and browser caches. A plugin-only non-undoable workaround exists but would not meet the intended quality bar.
- Generic JSON can contain private identifiers/settings. Future differential tooling should report safe paths/types and selected game fields; never log complete imported documents or identity/credential values. This research avoided those values.
- No reviewed public source supplies all names, descriptions, exact ranges, progression dependencies and licensed images. Text-first delivery is feasible; richer art, complete presets and sibling-title support remain conditional on evidence and rights.
