# PPSA13803 — Final Fantasy XVI Demo

**Medium; share Faith container with retail.** [Catalogue](https://prosperopatches.com/PPSA13803) explicitly identifies FF16 Demo. FAITHDATA and matching type/header words corroborate identity despite placeholder SFO labels.

Ten numbered autosaves, a plain game-save-data file and system-save-data occur under FAITHDATA directories. Gameplay is 1,040,124 bytes; system is 276 bytes, compared with a 1076-byte retail representative.

Verified: LE header size 16 at zero; per-file CRC at `0x04`; gameplay type `0x785930BD` at `0x08`; record prefix `01 00 00 00 28 01 00 00 59 7F 0D 0C` at `0x10`. System type is `0x0C044C6D`. **12/12 records** match CRC32 from `0x10` to EOF stored LE at `0x04`. H≈0.16 indicates sparse plaintext, not the PC encrypted/compressed PNG wrapper.

[FF16Tools CRC/wrapper source](https://github.com/Nenkai/FF16Tools/blob/master/FF16Tools.Files/Save/FaithSaveFile.cs) (MIT) and [primary save research](https://nenkai.github.io/ffxvi-modding/resources/other/save_files/) explain the relationship. PC XML/PNG support does not supply a proven PS5 field schema.
