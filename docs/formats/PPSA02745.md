# PPSA02745 — Tales of Arise

> **Historical reconnaissance — 2026-10-28.** Measurements and unknowns below belong to the
> original research pass. Later parsers, writers and policy decisions supersede its implementation
> leads; see [current plugin status](../PLUGINS.md) and each plugin README for supported behavior.

**Medium; documented PS5 AES/XOR blocks.** SFO and [catalogue](https://prosperopatches.com/PPSA02745) identify the game. SystemSaveData.sav is a separate 4096-byte opaque system blob; SaveData_000–002.sav are 760,856-byte gameplay slots.

Verified gameplay magic `30 16 05 10` at `0x32058`; length-like word `0x87BC0` at `0x3205C`. That span reaches EOF when measured from `0x32058`, **not** from ciphertext start `0x32078`: ciphertext length is `0x87BA0`, EOF `0xB9C18`. Upstream SHA1 region is `0x32060..0x32073`. Actual PS5 mode bytes `03 01` occur at **0x32074**, after that hash. Upstream notes saying 0x32068 overlap their own SHA1 region and disagree with the sample. No AES decryption or SHA1 validation was performed here.

[save-converters notes](https://github.com/ItsAllAboutTheCode/save-converters/blob/main/save_convert/tales_of/arise/save_NOTES.md) and [converter implementation](https://github.com/ItsAllAboutTheCode/save-converters/blob/main/save_convert/tales_of/arise/tales_of_arise_save_converter.py) (GPL-3.0) explicitly cover PC/PS4/PS5, public AES-256-ECB/XOR material, and PS5 test fixtures. Reference code was read as text, not executed. Do not apply the gameplay algorithm to SystemSaveData blindly.
