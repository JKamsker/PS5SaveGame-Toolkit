# PPSA01493 — Tiny Tina’s Wonderlands

**Medium; Gearbox GVAS plus obfuscated protobuf.** [Title-ID listing](https://platprices.com/ua/game/76610-tiny-tinas-wonderlands-chaotic-great-edition-pre-order-bundl) identifies Wonderlands. Branch bytes begin DAFFOD at `0x1A`; this is not another BL3 save. `profile` is user/profile state; `1` character slot 1.

Verified: GVAS version 2 and engine 4.20.3 from `0x0C`. First profile H=7.9984; character H=7.9995. No first-4KiB zlib candidate validated. Header similarity permits shared Gearbox framing, but says nothing about matching masks or protobuf schemas. PS5-specific deobfuscation/integrity and item serials remain unverified.

[xcier/TTWLSaveEditor](https://github.com/xcier/TTWLSaveEditor) (GPL-3.0) advertises PC/exploited PS4/SaveWizard saves; SaveBogoCrypt/ProfileBogoCrypt are relevant references. [somefunguy/TTWLSaveEditor](https://github.com/somefunguy/TTWLSaveEditor) (GPL-3.0) documents the Wonderlands editor lineage. Neither is proof of PS5 support.

Next: share only the GVAS framing with BL3, validate game/profile-specific payload decoding across all generations, then expose a meaningful primitive. Preserve unknown protobuf data and avoid inventing item names or treating BL3 item checksums as interchangeable.
