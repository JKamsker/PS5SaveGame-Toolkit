# PPSA04018 — The Witcher 3: Wild Hunt – Complete Edition

**Medium; REDengine SNFH/FZLC + raw LZ4.** [Catalogue](https://prosperopatches.com/PPSA04018), SFO quests and filenames establish identity. CheckPt/Manual .sav files are gameplay; same-stem .req lists required content (`content0;content1;content2;`). user.settings is INI-style, not JSON.

Verified: ASCII SNFHFZLC at zero; LE chunk count 1 at `0x08`, header/data offset `0xC0C` (3084) at `0x0C`. Table triples from `0x10`: compressed size, expanded size, optional end offset (zero here). First checkpoint: 198,010 compressed → 653,545 expanded; 3084 + 198010 = 201094, complete file length. Independent bounded LZ4 decoding validates all four primary .sav files and backups. Decoded payload begins SAV3 at offset zero; expanded lengths are 653,545 / 702,856 / 703,834 / 724,174. These raw blocks need no LZ4 frame magic.

[W3SavegameEditor](https://github.com/Atvaark/W3SavegameEditor) (MIT, PC-era) documents framing/sequential chunk reads; [LZ4 primary block specification](https://github.com/lz4/lz4/blob/dev/doc/lz4_Block_format.md) informed the independently written decoder. No upstream executable/code was run/copied. Neither reference certifies next-generation PS5 field schemas.
