# PPSA01288 — Sackboy: A Big Adventure

> **Historical reconnaissance — 2026-10-28.** Measurements and unknowns below belong to the
> original research pass. Later parsers, writers and policy decisions supersede its implementation
> leads; see [current plugin status](../PLUGINS.md) and each plugin README for supported behavior.

**Easy; Unreal GVAS.** [Title-ID mapping](https://prosperopatches.com/PPSA01288) confirms Sackboy; SFO says only “Spielstand”. `SaveGame/General` holds progression; `LevelImages_*` and `CostumeThumbnails_*` are image-related companions.

Verified: `GVAS` at zero; LE version 2 at `0x04`, package version 518 at `0x08`, engine 4.25.1 from `0x0C`. General is a promising tagged-property document. High entropy in image files is not evidence of encryption: LevelImages_04 has a valid zlib stream at `0x6E4`, consuming 12,144 bytes and producing 131,072 bytes. No game-specific checksum was established.

[SackboyWorldUnlocker](https://github.com/MsKrypt1/SackboyWorldUnlocker) is a PS4 General/world-unlock tool and cites [gvas-converter](https://github.com/13xforever/gvas-converter). The former has no explicit licence detected; the latter's licence was not audited. Reference their format knowledge; do not copy unlicensed code or assume PS5 compatibility.
