# PPSA01876 — Far Cry 6

> **Historical reconnaissance — 2026-10-28.** Measurements and unknowns below belong to the
> original research pass. Later parsers, writers and policy decisions supersede its implementation
> leads; see [current plugin status](../PLUGINS.md) and each plugin README for supported behavior.

**Hard; Dunia/custom profile.** SFO says Far Cry 6; [catalogue](https://prosperopatches.com/PPSA01876) confirms the ID. Only `profile.dat` and its backup are present; there is no campaign/character corpus.

Verified: length 1643; LE words `0x110`, `0x7CD`, `0x65B` at `0x00/0x04/0x08`. `0x65B = file length − 16`, a verified size relationship. Bytes `20 75 01 30` at `0x0C` are unclassified. H=6.8301 and a structured prefix do not establish the body's codec/encryption. No known frame or validated first-4KiB zlib stream. Header size/version/checksum semantics remain unknown beyond the size equality.

[Original PC Save Resigner/ToolKit](https://www.nexusmods.com/farcry6/mods/140) concerns UUID resigning and Ubisoft container conversion. Modification permissions are restricted; it is not a verified PS5 profile parser. No account identifiers were read or used.
