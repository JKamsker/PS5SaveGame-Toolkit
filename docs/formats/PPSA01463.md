# PPSA01463 — Borderlands 3

**Medium; Gearbox GVAS plus obfuscated protobuf.** [Title-ID mapping](https://prosperopatches.com/PPSA01463) and OAK branch bytes at `0x1A` confirm BL3. `profile` is profile/user state; `1` is character slot 1, matching upstream roles.

Verified: GVAS version 2, engine 4.20.3 from `0x0C`; first profile H=7.9984 and character H=7.9998. Clear headers precede largely non-text payloads. No first-4KiB zlib candidate validated. Upstream describes rolling-XOR BogoCrypt and protobuf; it is not an ordinary Unreal property list. PS5 masks and inner integrity have **not** been validated here. Item serials have independent encoding/integrity requirements.

Sources: [ZakisM/bl3_save_edit](https://github.com/ZakisM/bl3_save_edit) (GPL-3.0; explicitly PC/decrypted PS4, Rust parser/file_helper), [FromDarkHell/BL3SaveEditor](https://github.com/FromDarkHell/BL3SaveEditor) (GPL-3.0 C# save/profile editor), [apocalyptech/bl3-cli-saveedit](https://github.com/apocalyptech/bl3-cli-saveedit) (PC save/serial research; check licence before reuse). Their support statements do not certify PS5.
