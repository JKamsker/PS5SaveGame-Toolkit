# PPSA01506 — Immortals Fenyx Rising

**Hard; Ubisoft/Anvil custom container.** [Title-ID listing](https://platprices.com/be/game/36457-immortals-fenyx-rising) resolves identity. AutoSave/Options/dungeon files and SFO role descriptions corroborate a Ubisoft save set, but are not uniquely identifying themselves.

`Options.sav` is configuration; AutoSave01–05, ManualSave01 and DungeonEntranceSave0 are progression candidates. The separate 8-byte `data` companion is inferred graphics-mode state from its directory/SFO.

Verified main header: `AC DB FE 00` at zero; LE 0x36 at `0x04`. Options words at `0x08/0x0C` are 0/4, autosaves 2/6. `0x10` varies while `0x14..0x1B` agree in representatives; possible identifier/integrity fields, **not verified checksums**. H≈6.9 fits compressed/obfuscated data; no framed codec or first-4KiB zlib stream validated.

[ACSaveTool](https://github.com/linuslin0/ACST) explicitly supports PC Immortals with account-ID binding. It is a release tool with noncommercial/research restrictions, not a permissive source dependency or proven PS5 parser. No PS5 payload codec/key/integrity match was found in this reconnaissance.

Next: map container records using controlled option-only and currency-only pairs. Resolve codec and integrity before editing; investigate the small graphics companion separately. An Anvil association is a game/engine lead, not a verified cross-game save schema.
