# PPSA10665 — Final Fantasy XVI

> **Historical reconnaissance — 2026-10-28.** Measurements and unknowns below belong to the
> original research pass. Later parsers, writers and policy decisions supersede its implementation
> leads; see [current plugin status](../PLUGINS.md) and each plugin README for supported behavior.

**Medium; Faith inner documents, high-value shared work.** [Catalogue](https://prosperopatches.com/PPSA10665), FAITHDATA paths and matching demo headers confirm identity. Some SFO TITLE_ID values are stale PPSA01288/PPSA01325 despite the outer PPSA10665 path: do not propagate those generated metadata errors.

FAITHDATAAUTO/game-save-data00–09 form an autosave ring; game-save-data is manual/special state; system-save-data is system/settings. Roles follow names/directories, not complete schemas.

Verified: header size 16 at `0x00`; CRC32 at `0x04`; type-like `0x785930BD` at `0x08` for gameplay, `0x0C044C6D` for system. Gameplay starts with 1 at `0x10`; next word differs: 0x618 in 1,068,724-byte retail autosaves versus 0x128 in 1,040,124-byte records. **CRC32(bytes[0x10..EOF]) = LE u32 at 0x04 on 60/60 records**, including duplicate paths. Very low entropy shows these supplied inner files are already plaintext.

[FF16Tools/FaithSaveFile.cs](https://github.com/Nenkai/FF16Tools/blob/master/FF16Tools.Files/Save/FaithSaveFile.cs) (MIT) defines this CRC repair, plus a **PC outer PNG/faTh XOR/dictionary-zlib wrapper**, which must not be added to PS5 output. [Primary modding research](https://nenkai.github.io/ffxvi-modding/resources/other/save_files/) links templates/XML research. No downloaded implementation was executed.

Next: one versioned Faith inner-document plugin for retail/demo, CRC repair first, then prove gameplay meanings across snapshots. Record schemas/ranges remain unknown; container similarity does not permit silently converting demo layouts.
