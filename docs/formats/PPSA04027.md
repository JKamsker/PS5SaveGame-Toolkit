# PPSA04027 — Cyberpunk 2077

**Easy JSON coverage; medium gameplay plugin.** [Catalogue](https://prosperopatches.com/PPSA04027), sav.dat/metadata names and SFO Streetkid quest confirm identity. settings.json is configuration; metadata.9.json is slot metadata, not progression. sav.dat is gameplay; user.gls separate global/profile state; screenshot.png an image.

Verified JSON: UTF-8 objects, settings 45,415 bytes with top-level version 136; metadata 2610 bytes. GenericJson conformance tests edit/reopen these documents while preserving all untouched bytes. Game meanings and constraints remain Unknown.

Verified binary: sav.dat begins VASC (word-order CSAV), FZLC at byte `0x19`; 22 descriptor triples `(offset, stored size, expanded size)` begin at `0x21`. First chunk: offset 3105 (`0xC21`), size 60,824, expanded 262,144. Its 8-byte 4ZLX wrapper precedes raw LZ4. Independent bounded decoding validates all 22 chunks, yielding **5,607,178 bytes**. user.gls starts SLGR, size 396; it was not decoded as a gameplay save.

[CyberCAT](https://github.com/WolvenKit/CyberCAT) (MIT, archived PC editor; CompressionHelper.cs) confirms framing. [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259) defines JSON syntax. PC schema versions do not establish PS5 writing compatibility.

Next: use format.json now for JSON primitives; implement a separate versioned CSave node/container plugin for gameplay. Writing binary requires chunk tables/footer offsets and any integrity/dependencies to be rebuilt and validated. user.gls integrity is unknown; never rewrite it as JSON.
