# PPSA08330 — God of War Ragnarök

> **Historical reconnaissance — 2026-10-28.** Measurements and unknowns below belong to the
> original research pass. Later parsers, writers and policy decisions supersede its implementation
> leads; see [current plugin status](../PLUGINS.md) and each plugin README for supported behavior.

**Hard; Santa Monica custom save.** [Catalogue](https://prosperopatches.com/PPSA08330), GOWRSAVE names and SFO realm/quest labels establish identity. GOWRSAVE0–65 are gameplay/history slots; userpreferences is a separate 696-byte settings record.

Representative SAVE0 prefix: `1A B5 08 65 00 00 00 00`, plausibly a LE Unix timestamp (**inferred**); LE 8 at `0x08`, `0x00513040` at `0x0C`, `0x2B8` at `0x10`, `0x008C0400` at `0x14`, variable word at `0x18`. H=3.389 with many zeros argues against blanket ciphertext/full-file compression. No framed codec/zlib match. Preferences differ (word 31 at `0x08`). SAVE0 shrinks by 2,380,645 bytes between repeated-path generations: a universal fixed offset map would be unsafe. Checksum/version semantics remain unknown.

[Community SaveWizard resource codes](https://github.com/sterben-Dev10/SaveWizard-Resources/blob/main/SaveWizard-Codes/GOW%20Ragnarok%20%5BSaveWizard%5D.txt) provide IDs and PS4/export codes, not verified offsets for these PS5 versions; reuse licence not established. [Original commercial editor author](https://codesprince.com/2024/09/24/pc-editor-for-gow-ragnarok/) describes separate version-limited PC and PS4/PS5 editors; closed source, not a portable algorithm.
