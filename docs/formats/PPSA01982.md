# PPSA01982 — DOOM Eternal

> **Historical reconnaissance — 2026-10-28.** Measurements and unknowns below belong to the
> original research pass. Later parsers, writers and policy decisions supersede its implementation
> leads; see [current plugin status](../PLUGINS.md) and each plugin README for supported behavior.

**Hard; idTech profile.** SFO and [catalogue](https://prosperopatches.com/PPSA01982) identify the game. Only `PROF`, 493,113 bytes, plus its backup exists; campaign editing is not supported by this corpus.

Verified prefix: `A9 0D 8D AA 00 00 00 02 FB 14 32 6A`; a DOOM_ETERNAL marker starts at `0x12`. Mixed structure and H=4.7196 contradict whole-file uniform ciphertext. Big-endian 2 at `0x04` is a version candidate; word at `0x08` an integrity candidate. Neither meaning is validated. No framed codec or first-4KiB zlib stream was established.

[DOOMSaveManager](https://github.com/GoobyCorp/DOOMSaveManager) is PC transfer/manager research. Crypto.cs defines CalcProfileHash over `0x0C..EOF` using a FarmHash-derived 32-bit algorithm, with separate AES-GCM storage helpers. No repository licence was detected, so do not copy it. [Google FarmHash](https://github.com/google/farmhash) is the MIT primary algorithm reference; exact PS5 variant/coverage has not been checked.
