# PPSA07696 — Ridge Racer 2 (PSP classic on PS5)

> **Historical reconnaissance — 2026-10-28.** Measurements and unknowns below belong to the
> original research pass. Later parsers, writers and policy decisions supersede its implementation
> leads; see [current plugin status](../PLUGINS.md) and each plugin README for supported behavior.

**Easy emulator JSON; hard/unknown binary gameplay.** SFO says RIDGE RACER 2; UCES00422 agrees with the [Apollo PSP database](https://bucanero.github.io/apollo-saves/PSP/). [PPSA07696 listing](https://platprices.com/in/game/151519-ridge-racer-2) identifies the PS5 wrapper.

imgui_emu_option.json is emulator configuration: 1320 bytes, UTF-8 object with two root members; options/cubic_A = -0.5, checked by plugin tests. DATA.BIN is the 26,628-byte legacy game payload, H=1.8379: its low-entropy interior suggests structures rather than whole-file ciphertext, but fields/integrity are unmapped. ICON0.PNG/PIC1.PNG are images, ICON1.PMF begins PSMF0014, and savedata_dir.stat is companion metadata. No known compressed frame or validated first-4KiB zlib stream in DATA.BIN.

[PPSSPP](https://github.com/hrydgard/ppsspp) (GPL-2.0-or-later) is primary PSP savedata implementation research; PS5 wrapper support is not claimed. [RRUnpacker](https://github.com/Nenkai/RRUnpacker) (MIT) unpacks Ridge Racer **assets**, not DATA.BIN saves. Apollo supplies reference saves, not a licensed field parser.
