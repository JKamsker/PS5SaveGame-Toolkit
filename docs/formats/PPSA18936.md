# PPSA18936 — Final Fantasy VII Rebirth Demo

> **Historical reconnaissance — 2026-10-28.** Measurements and unknowns below belong to the
> original research pass. Later parsers, writers and policy decisions supersede its implementation
> leads; see [current plugin status](../PLUGINS.md) and each plugin README for supported behavior.

**Medium; share Rebirth container, retain demo schema.** `ff7rebirthdemocommon` explicitly identifies the demo; [external ID listing](https://sharpemu.app/game/PPSA08666/?os=windows) associates PPSA18936 with Rebirth. Placeholder SFO does not identify the game itself.

Common state is 1056 bytes; ff7rebirth000/001 are 23,381,104-byte gameplay files. Verified: common repeats COSD at `0x10`; gameplay repeats RESD there, with next pointer `0xE4330` at `0x04` and `0xE4320`/1 at `0x08/0x0C`. Both numbered files walk **275 linked records**, ending at tail `0x164C460`, precisely EOF `0x164C470`. Retail has the same dimensions/initial wrapper fields. Sparse plaintext is observable; field-offset equivalence and additional integrity remain unknown.

[KingdomSaveEditor](https://github.com/Xeeynamo/KingdomSaveEditor) (GPL-3.0) provides the Remake chunk idea, not supported Rebirth/demo schemas. [PC retail Rebirth editor](https://www.nexusmods.com/finalfantasy7rebirth/mods/2072) is a further gameplay lead; demo/PS5 support and reuse licence are not established.
