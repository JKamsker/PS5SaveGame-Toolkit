# PPSA01651 — YouTube (application)

**Excluded from gameplay editing.** SFO explicitly says YouTube; [catalogue content ID](https://prosperopatches.com/PPSA01651) ends YOUTUBESIEE00000. This is an application, not an unidentified game.

ZIP metadata lists a 7020-byte origin storage file under STARBOARD, with basename `aHR0cHM6Ly93d3cueW91dHViZS5jb20vdHY=` (the public YouTube TV origin in base64), and a 1 MiB `sce_sdmemory/memory.dat`. Both have repeated paths and console backup directories.

Only filenames, lengths and SFO identity metadata were inspected. **Application payloads were deliberately not read**, because they can contain session/account secrets and the workspace instructions prohibit reading those. Consequently magic, entropy, codec, checksums and payload differences are unknown; no unsupported binary-format claim is made.

[Official Cobalt/Starboard source](https://github.com/youtube/cobalt) explains application platform storage; BSD-style licensing requires individual-file checks. It is not a PS5 savedata parser or game editor.

Next: exclude this title from gameplay plugin discovery and preserve it opaquely. Any future settings research should use synthetic signed-out data. Reading private application state brings no value to this game-save project.
