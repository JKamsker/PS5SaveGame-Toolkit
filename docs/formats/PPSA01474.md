# PPSA01474 — Ratchet & Clank: Rift Apart

**Medium; Insomniac i29/DAT1.** [Catalogue content ID](https://prosperopatches.com/PPSA01474) ends RATCHETCLANKRIFT. i29 names and SFO missions naming Rivet/Clank independently confirm identity. `i29-userprefs.save` is preferences; `i29-s.save` is gameplay. Same basenames in different slot directories must stay separate.

Verified DAT1 structure: bytes `31 54 41 44` at zero are LE `0x44415431`; word at `0x04` is 8, size at `0x08` agrees with the inspected file lengths. Ushort section/auxiliary counts at `0x0C/0x0E`; `(u32 tag, offset, size)` descriptors begin at `0x10`. Representative preferences: one section, tag `0x2EE91673`, offset `0x900`, size `0x970`, EOF `0x1270`. Gameplay representative has 19 sections. The inspector checks all section bounds.

[ALERT](https://github.com/Tkachov/ALERT) (GPL-3.0, dat1lib/types/dat1.py) confirms container framing across Insomniac assets; [RiftRipper](https://github.com/VELD-Dev/riftripper) is C# asset/level research (PC supported, PS5 uncertain; licence not audited). Neither establishes save-specific field schemas or integrity.

Next: preserving DAT1 section reader, then preferences and one proven gameplay value. Section meaning/checksums/compression within sections remain unknown. A reusable Insomniac container is worthwhile, but this corpus only proves Rift Apart framing.
